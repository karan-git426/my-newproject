Welcome to the DevOps training portal. To make sure your local environment and your GitHub Fork match the upstream repository, follow the update guide below regularly before starting tasks.

How to Update Your Fork (Fork-ஐ Update பண்ணுவது எப்படி?)

1 Add Upstream Remote

Original main repository-ஐ உங்கள் லோக்கல் ப்ரொஜெக்டில் 'upstream' ஆக இணைக்கவும்:

git remote add upstream https://github.com/ORIGINAL_OWNER/REPO_NAME.git

2 Fetch Latest Code

Upstream-ல் இருக்கும் புதிய மாற்றங்களை உங்கள் கணினிக்கு கொண்டு வரவும்:

git fetch upstream

3 Merge Changes

மாற்றங்களை உங்கள் மெயின் பிரான்ச்சில் மெர்ஜ் (Merge) செய்யவும்:

git checkout main
git merge upstream/main

4 Push to Fork

இப்போது அப்டேட் செய்யப்பட்ட லோக்கல் ஃபைல்களை உங்களது சொந்த கிட்ஹப் போர்க்கிற்கு அப்லோட் செய்யவும்:

git push origin main
